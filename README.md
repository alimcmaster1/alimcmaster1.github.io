# Alistair McMaster

Personal site for writing, photographs, and CV.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `/` — full-bleed home
- `/blog` — writing
- `/photos` — gallery
- `/cv` — curriculum vitae

Content lives in `src/content/`. Replace images in `src/assets/photos/`.
